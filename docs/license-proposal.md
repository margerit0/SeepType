# 新写代码的许可决定

2026-11-07。产品名已确认为 **拾词输入法（StudyIME）**。用户在阅读以下建议后，明确确认新写代码使用 **GPL-3.0-or-later**；决定记录在 [code-license.json](../licensing/code-license.json)。正式声明见 [COPYING.md](../COPYING.md)，完整条款见 [LICENSE](../LICENSE)。

建议对新写代码采用 **GPL-3.0-or-later**。Weasel 修改版的整体分发必须满足其 GPLv3 条款，新代码采用兼容的 GPL 路线可减少混合授权的维护成本。`or-later` 允许接收者选择 GPLv3 或自由软件基金会未来发布的 GPL 版本；它不表示必须升级到未来版本。上游文件若仅授权 GPLv3，不会被本项目的选择自动改成 `or-later`。

| 选择 | 对开发和分发的影响 |
| --- | --- |
| 采用 GPL-3.0-or-later | 新代码成为明确授权的自由软件。分发时保留必要声明，标记修改，按要求提供与二进制对应的源码及构建/安装材料。接收者可修改、再分发及商用，不能额外禁止商业使用或竞争产品。单纯本机私用不要求把修改公开到互联网。 |
| 暂缓选择 | 本机开发、构建和评审可以继续；不会替作者授予新代码的公开使用权，正式发布检查会继续阻止发布。后续选择仍需兼容实际结合的 Weasel 及其他组件。 |

CC-CEDICT 衍生词库的 **CC BY-SA 4.0** 是已有数据来源条件，不是可任意替换的代码许可。须保留署名、许可和变更说明，适用的改编数据遵循相同方式共享条件。软件和数据分别列明；词库许可不会自动覆盖整个软件，代码选 GPL 也不会取消数据的义务。

选择主项目许可不能替代第三方核验。尤其是捆绑二进制的静态依赖、WTL 头文件的 MS-PL、中文基础词典及转换数据，须按 [软件许可汇总](software-licenses.md) 的证据逐项处理。当前不宣称整个安装包已经具备公开发布条件。
