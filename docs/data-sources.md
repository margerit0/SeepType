## 词典策略

| 来源 | 已查材料与授权 | 本项目处理 |
| --- | --- | --- |
| 自拟原型样例 | `prototype/ime-candidates.html` 的 dictionary 数据；18 个不同中文词形，20 条场景记录（含分段重复词形）；未人工验收 | 全部为 `test-only`，没有 `approved-for-distribution` 记录，不作为正式词库 |

| CC-CEDICT | [官网](https://cc-cedict.org/wiki/) 当前标注 CC BY-SA 4.0；[许可正文](https://creativecommons.org/licenses/by-sa/4.0/legalcode.en) 与 [许可摘要](https://creativecommons.org/licenses/by-sa/4.0/) | 推荐作为人工筛选的中英词库候选，先约 200 条；下载时核对文件头、快照日期、哈希与网页许可是否一致，未核对前不打包 |
| 第三方商业词典、参考产品词库、来源不明汇总包 | 未取得可再分发授权 | 不采用，不因“可下载/有 API”推断能离线再分发 |

CC-CEDICT 的处理要求：保留来源/作者等必要署名、许可链接和变更说明；对删选、改写、短释义整理形成的适用衍生数据按相同方式共享条件发布。不能通过手工重打、压缩或改文件格式消除许可义务。软件源码和词库分开列许可，不把数据许可误写成整个软件许可；分开存放本身也不免除义务。

[官方开发者说明](https://cc-cedict.org/wiki/developers) 指出条目可能仅引用其他词条。因此不应把第一条斜线字段直接当作可提交英文：需要处理参见、异体、量词、专名、语域和词性。首版优先审核明确的日常词/短语；去除不完整解释。存在多个不易取舍的词义、仅说明性文字或歧义词形时留空。

每条进入正式词表的记录至少保存：中文精确词形、显示释义、实际英文提交值、来源条目与快照、许可、修改说明、审核状态/审核者。`test-only` 与 `approved-for-distribution` 分开标记；导出只能包含同时通过释义审核和许可核对的记录。默认显示和提交为同一短英文；需要说明性附注时必须把英文提交值另外人工审核，不能将“see ...”等原始词典说明直接上屏。

不从用户聊天中挖词、不保存上下文、不用在线翻译补洞。完整输入句子的学习记录不属于词库数据来源。
