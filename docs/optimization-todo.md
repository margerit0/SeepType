## 后续排序优化

以下高级排序单独排期，不作为本轮词频完成条件，也不自动列为 dev.3 的发布前置。

- [ ] **同一输入串的选择偏好**：评估全拼、简拼之间是否共享偏好，保持完整匹配、正确读音和单字可达性。用真实候选回放比较，避免一次选择影响所有相似拼音。
- [ ] **上下文排序**：评估本地二元、三元词搭配，以及它们与基础词频、个人词频的组合；明确跨句、跨应用的上下文边界。
- [ ] **按时间淡化旧偏好**：对比原生 Rime 按使用进程计算的动态权重与按自然日衰减的效果；不能直接照搬青简的 90 天参数。
- [ ] **精细控制**：评估手动置顶、降权、批量清理与备份恢复。当前“忘记此词”按候选的当前读音恢复基础排序；内置词不会从基础词库删除。
- [ ] **整句模型重排**：仅在前面的统计策略有明确不足时评估本地模型；先定义质量、延迟和内存预算，不把模型调用放进每键同步路径。

比较基线：首选命中率、所需选词按键数、误学习后的恢复、简拼/整句候选、重启一致性，以及每键 p95 延迟。每次优化都应与当前原生方案比较。
