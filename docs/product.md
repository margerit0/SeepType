# MVP 需求 v0.1

更新：2026-10-31。阶段 1 完成、阶段 2 原型已按用户要求缩小为 v0.5 横向候选条；以下为推荐需求基线，最终设计尚未确认。

## 用户与场景

面向日常用中文办公、聊天、写笔记，希望顺便积累基础英语词汇的 Windows 用户。中文输入效率与正确性优先，学习功能不接管用户写作。个人开发者维护，优先复用成熟引擎。

用户已确认：开源发行方向；Windows 11 x64；简体中文全拼；优先验证记事本、浏览器、VS Code。具体应用版本在实测时记录，不据此承诺兼容。

## 核心流程

1. 输入拼音，沿用 Rime 产生的中文候选与排序。
2. 学习模式开启时，可靠匹配的候选上方显示一条简短英文释义。
3. 空格、数字键、普通左键点击按原方案选择中文；回车保持原方案行为，不改造成英文提交。
4. 主动使用专用操作才输入英文。原型提案：`Ctrl+Shift+Enter` 提交当前高亮候选的英文；右键菜单提供带完整英文的“输入英文”。不绑定单独 Shift、Enter 或直接点击英文行。
5. 随时关闭学习模式，英文提交停用，继续正常中文输入。状态和设置保存在本机。

## 必须交付

正常全拼输入、英文在上中文在下的候选窗口、学习开关、明确的英文提交、基本设置（开关、字号、浅色/深色、快捷键预设及说明、词库版本与许可）、可重复构建和安装/卸载的测试版本。

释义先使用约 200 条人工检查的日常词与短语；这是验证规模，不是最终覆盖率承诺。只查候选最终显示的中文词形，不猜测上下文、不拆整句拼接翻译。无可靠匹配留空；多义词只保留人工选定常用义，无法安全选择则不显示。长英文省略显示但提交完整审核文本，不提交省略号。

第一版英文提交建议只覆盖完整词或短语候选：候选须覆盖整段当前组合串，且没有先前确认的分段。存在剩余拼音时暂不提供英文提交，避免丢字；中文分段输入不受影响。此限制会在原型中明确演示并随设计确认。

不包含移动端、macOS、整句 AI 翻译、语音、账号、云同步、支付、复杂复习、遥测、自动更新。学习模块不保存完整输入内容、不读取聊天上下文、不发送联网查词请求。引擎本地用户词典的保存行为须单独核查并说明，不宣称整个输入法零落盘。

## 技术与数据假设

优先组合 Weasel + librime + librime-lua + 本地词表。Lua 负责查词与键盘逻辑，候选布局预计需要小范围 Weasel 修改；源码调查支持此方向，运行可行性尚未验证。依据和补丁边界见 [architecture.md](architecture.md)。

Weasel 为 GPLv3；librime、librime-lua 为 BSD-3-Clause。开源方向已获用户同意。扩充词库候选 CC-CEDICT 当前标注 CC BY-SA 4.0，实际分发须核查所取快照并履行署名及相同方式共享要求；人工筛选不能消除来源义务。详见 [data-sources.md](data-sources.md)。

## 决策与通过条件

无需追加长问卷。默认面向日常通用词汇；用户已明确旧 A/B 原型过大，现用接近日常输入法尺寸的 v0.5 横条确认密度、英文提交方式和上述分段限制。

进入正式开发前：用户明确确认设计，并完成真实候选释义、双行原生布局、英文提交、无释义退化与性能的小实验。最终逐项记录三类应用、标点/模式切换、连续输入、翻页、显示缩放、安装卸载；未执行项写“未测试”。
