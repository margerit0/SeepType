# Android preview.3 本地整合验收

2026-11-22。`codex/android-preview3-integration` 是本地候选，**尚未达到更新 `codex/android-dev` 或公开发布的门槛**。旧开发线仍在 `fe73ce6`，另有本地归档 `archive/android-dev-preview.2`。Windows 开发线未改动。

## 被测构建

- `0.1.0-preview.3`，`versionCode=3`。产物从 `d7bf40853dc5b4755a696c73d994b559e354ac05` 复核；仅改测试运行器的提交没有改变 Release APK。
- 本地开发签名 Release APK SHA-256：`ab0025d8fcd65a3e9eeb7a48eefe06b6d3a5627279b6c496ff48a84267ab4278`。
- 签名证书 SHA-256：`784a9a164476e55085478a253b36d224d64d567ba243ac5704a73ab641469c8e`。这是开发签名，不是商店签名。
- Debug 和 Release 的生成资源按文件核对一致，资源版本为 `679241500030b529aaa5`；测试 APK 含固定快照的 702 项原生用例。打包时发现并清除了旧词库遗留的嵌套清单；未替换 preview.3 的词库和界面。

## 本轮结果

| 检查 | 结果与范围 |
| --- | --- |
| 本机构建 | Release、Debug 和测试 APK 组装成功；35 项主机单测、13 项 JVM 单测通过。签名、双 ABI 及原生库 16 KB 对齐通过；没有 16 KB 实机运行结果。 |
| API 30 · Debug | 702 项原生词库用例、54 个会话／原生保护断言、420 个离线专名 × 3 种方案、14 项资源恢复和缓存键盘绘制测试通过。 |
| API 35 · Release 重开 | 40 次隐藏后重开均记录到新的就绪绘制，IME 进程保持不变。这里的终点是 Compose 绘制，不是物理显示。 |
| API 35 · Debug 剪贴板 | 112 项通过，包括文字密码、数字密码和隐私编辑框中不能打开历史、不能留存对应的合成剪贴板文本。 |
| API 35 · Release 三方案与新资源 | 多次运行中，全拼、自然码、小鹤均已选词并显式提交英文；「解决」的 `solve` / `settle` 均可查看，显式点击才提交 `solve`，并能输入离线专名「那维莱特」。整套用例仍未全绿：一次在分段后空格提交的断言处失败；调整后的一次在「还」的 `return` 候选查找处停止，没有执行到调整后的最后一步。 |
| API 30／35 · 完整 Release 编辑器交互 | 未通过。API 35 的部分断言（中文选词、显式英文提交、不重复提交）通过，但完整测试和设置恢复未通过；不能视为 Release 密码框覆盖完整。 |
| 物理设备 | 未连接、未测试；旧 `preview.2` 的手机结果不能替代本次验证。 |

API 30 的设置／剪贴板测试及 API 35 的部分 Release 流程出现无障碍／Compose 调用栈异常。用集成前 `f8324c9` 的 APK 在 API 30 做对照，自动化也出现了无障碍栈崩溃。这不能证明两者同根因，也不能用通过的子项覆盖失败。原始报告保存在本机 `.cache`，不随公开源码发布。未重新执行完整性能基线。
