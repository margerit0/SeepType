# Android preview.3 本地整合验收

2026-11-22。`codex/android-preview3-integration` 是本地候选。首发所需的核心模拟器用例已复验通过；公开历史的素材分发核对和最终发行签名尚未完成。开发线仍在 `fe73ce6`，另有本地归档 `archive/android-dev-preview.2`。Windows 开发线未改动。

- 本地开发签名 Release APK SHA-256：`ab0025d8fcd65a3e9eeb7a48eefe06b6d3a5627279b6c496ff48a84267ab4278`。
- 签名证书 SHA-256：`784a9a164476e55085478a253b36d224d64d567ba243ac5704a73ab641469c8e`。这是开发签名，不是商店签名。
- Debug 和 Release 的生成资源按文件核对一致，资源版本为 `679241500030b529aaa5`；测试 APK 含固定快照的 702 项原生用例。打包时发现并清除了旧词库遗留的嵌套清单；未替换 preview.3 的词库和界面。

## 首发核心复验

离线组装得到与上文相同的优化版 APK（SHA-256 `ab0025d8…`）。以下结果都核对了模拟器上实际安装的 APK；只使用项目 API 35 模拟器与合成输入，没有测真机。

| 检查 | 复验结果 |
| --- | --- |
| 优化版输入 | 22 项通过。全拼、自然码和小鹤中文选词及显式英文提交通过；覆盖多义项、多音字、离线专名和分段候选保护。 |
| 优化版键盘重开 | 同一输入法进程连续 40/40 次在重开后记录就绪绘制；未重跑完整性能测试。 |
| 优化版剪贴板保护 | 18 项通过。普通文本先验证可被记录；文字密码、数字密码及禁用个性化的编辑器中，不能打开历史，切回普通编辑器时未发现对应合成条目。 |
| 普通触屏 | 无障碍关闭时 7 项通过。验证空编辑器的中文触屏选词，以及重开后空格提交原始拼音。固定坐标选择第一候选允许「公园」或「公元」；按名称选「公园」由上面的输入用例单独验证。 |
| 构建与数据 | 49 项主机单测、13 项 JVM 单测通过；APK 内固定资源清单、署名文件、Debug/Release 资源一致性和 702 项引擎用例夹具通过校验。 |
| 发行流程演练 | 独立的无签名优化包可离线构建；用本机开发证书测试签名后，内容与已测试优化包一致，签名、双 ABI 和原生库 16 KiB 静态对齐校验通过。演练产物不可发布。 |

本轮核心用例未复现旧的无障碍栈故障。这不是历史根因已证明解决，旧的完整编辑器交互和性能报告也不视为已通过。最终发行证书签出的 APK 仍须独立复验。
