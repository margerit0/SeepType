## 并行工作的规则

- 安卓任务使用本聊天绑定的 worktree，不返回 `.` 修改文件或切换分支。当前目录用 `git rev-parse --show-toplevel` 核对。
- 每个任务只在自己的工作树中编辑、暂存和提交；检查当前分支与暂存差异后再提交。
- 工作树共享 Git 对象和分支引用，但工作文件、HEAD 与索引分别独立。不要强制让两个工作树同时检出同一个分支。
- 各自的构建输出与临时数据留在自己的工作树。Git 忽略的缓存不会自动复制，安卓环境准备继续按 [开发计划](android-plan.md) 的 P0 执行。
- 合并同一文件的同一位置仍可能出现正常的 Git 冲突；这与两个任务直接覆盖同一工作目录是两种问题。
