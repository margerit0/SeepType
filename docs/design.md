# 候选条设计 v0.5

更新：2026-10-31。**用户已明确确认以 v0.5 为设计基线，进入小狼毫／Rime 最小技术验证。**

确认范围：紧凑横排、英文在上、中文在下、圆角且无左侧深色条、学习开关收缩动画、翻页动画、明确英文提交操作。若原生验证需要调整设计，先说明原因和替代方案。

入口：[可操作原型](../prototype/index.html)；[原型源](../prototype/ime-candidates.html)；[验证记录](../prototype/qa-slim.json)。旧两套方案保存在 [v0.2 归档](../prototype/archive/v0.2/index.html)，历史调查与设计说明也在同目录。

## 当前方向

收敛为一排横向候选。保留正常中文字号，在中文上方加一行小英文。移除候选窗顶部的独立拼音/学习栏、底部操作栏和常驻详情，不再把纵向学习面板作为当前提案。用户切换到过旧学习型并不等于批准该方案。

用户截图仅用于观察密度、间距、横向工具区；没有复制微软品牌、素材或代码。截图的设备缩放未知，不把图像像素直接当作本机逻辑像素。

## 操作及展示规则

- 空格、数字、普通点击（包含英文行）仍提交中文。方向键切换候选，PageUp/Down 翻页；真实拼音方案行为另行核验。
- 翻页时，新页沿翻页方向从侧面 10px 处滑入并淡入，180ms；旧页向相反侧滑出并在 120ms 内淡出，缓动 cubic-bezier(.22,1,.36,1)。下一页从右进入，上一页从左进入。边框、工具区和高度保持稳定。首页/末页越界不播放，首次加载和普通拼音更新不播放。
- 页码及可提交候选立即切换；退出画面仅作视觉副本，禁用交互和无障碍读出。连续翻页取消前一次过渡，不排队；选词、切换学习模式或更换拼音会立即清理过渡层。减少动态效果偏好下直接换页。
- Ctrl+Shift+Enter 提交当前候选完整英文；或右键候选 / 点右侧更多，再明确点“输入英文”。快捷键也可设置为 Alt+Enter，真实应用冲突未测试。
- 英文单行省略，提交不带省略号。完整释义通过悬停、F2 或菜单查看，以浮层呈现，不改变候选条尺寸。Esc/关闭按钮/离开相关区域收起。
- 无可靠释义保留英文行空位，中文正常选词，英文操作禁用并说明原因。多义词只用一条示例常用义，不猜测上下文。
- “学”按钮随时关闭学习模式，文字变“关”。英文行高度与间隔收至 0，候选条同步缩至单行；重新开启立即反向展开，不等下一轮输入。此规则按用户最新要求替代 v0.3 的“本轮保留高度”。
- 高度过渡 240ms，缓动 cubic-bezier(.22,1,.36,1)；英文透明度过渡 160ms。保持条的顶部、宽度、拼音、当前页和选中项。连续开关从当前尺寸反向过渡。首次加载不播放；减少动态效果偏好下关闭过渡。输入或翻页时立即更新候选状态，不等待动画结束。
- 关闭动作立即禁用英文提交、释义浮层和英文无障碍读出，视觉收起过程不延迟这个状态。仅学习模式开关复用候选节点，避免文字重建打断过渡。
- 候选变更、翻页或切换场景会使旧菜单失效。输入候选只覆盖部分拼音时禁用英文提交，中文选择保留后续拼音。
- 设置仍在原型外层工具区；在组合完成或 Esc 取消后打开，不把设置面板常驻在候选窗中。实际产品的托盘/设置入口待原生阶段验证。
- 窄预览容器减少每页显示项数，保持一排，不把候选堆成多排或强行缩小文字。该网页响应式演示不等于已验证 Rime 能动态改变页大小，原生屏幕边缘策略另验。

外层“场景、主题、练习文字、状态提示”是原型试用工具；设计尺寸衡量的是带中英文候选及右侧工具的候选条。

## 验证与边界

v0.5 已在浏览器核查鼠标与 PageUp/Down 翻页、连续翻页、末页宽度和边界、中英文提交、学习开关与翻页互相中断；浅深色均操作检查。测得上一页过渡中横向偏移 -5.47px、透明度 0.453，结束后恢复原位并清除副本。详见 [qa-paging.json](../prototype/qa-paging.json)。仅为网页原型验证。

本次实测：55px / 38px 双向切换、连续开关、当前拼音/第二页选中项保留、关闭后英文禁用和中文正常提交。记录见 [qa-motion.json](../prototype/qa-motion.json)。预览容器动画时短暂出现滚动条，原先会触发分页重置；已对宽度变化等待稳定 100ms，并在真实调整页大小时保留选中词。

qa-slim.json 保留 v0.3 的长释义、英文提交、缺词/分段、主题、320px 窄预览历史检查；其中“本轮保持高度”已被本次规则替代。减少动态效果规则已实现，系统偏好切换未测试；原生动画及 Windows DPI 均未测试。

模拟词表仍为 test-only，未人工验收。未接入真实引擎、未验证 Windows 显示缩放、未测试实际应用、未安装输入法。下一步先由用户确认此密度与交互，再进入最小技术验证。

圆角修订已在浏览器确认：外框 14px、候选项 10px、高度仍为 55px。当前实拍：[圆角候选条](../prototype/previews/rounded-clean.jpg)。原 slim-* 截图保留为 v0.3 历史预览。
