# 拾词安卓交互设计参考

2026-11-11 新增[紧凑候选栏样稿](compact-candidates/README.md)：待机工具与输入候选共用状态栏，取消独立拼音与“英文”行，英文在上、中文在下，常见宽度显示 6–7 个候选。该目录保存待确认的最新界面方向及独立预览，供后续实现使用。

2026-11-08，用户强调美观并认可本聊天中的交互示意。此目录保存当时的设计参考，供 [安卓与 Rust 开发计划](../../docs/android-plan.md) 使用。

- [index.html](index.html)：可在浏览器打开的交互示意，包含独立预览包装。
- [concept.html](concept.html)：交互示意的可编辑源片段；包含产品样式和固定示例，不是 Android 源码。
- [light.png](light.png)、[dark.png](dark.png)：同一网页示意的浅深色截图，供文档直接查看。

初始方向为清浅绿、柔和按键、9 CSS px 按键圆角，以及英文在上、中文在下的候选。默认英语显示开启；交互支持浅深色切换、英语开关、普通中文选词、长按／按钮查看释义、明确英文提交和模拟键盘。

网页示意已在本聊天中检查浅深色、开关、释义、中文／英文插入与 320 CSS px 宽度。它使用固定例词和模拟笔记；相关观察不代表真实 Android 生命周期、Rime 输入质量、Compose 性能或真机应用兼容性。示例释义不能导入运行词库。截图作为视觉参考，具体颜色与结构以源片段为准。

此目录从聊天设计文件按原字节保存；未携带预览用 npm 依赖或浏览器测试工具。独立包装可能从获准 CDN 加载图标等预览资源，界面内的输入与查词没有网络 API 请求；这些预览依赖不等于 Android App 的运行依赖或联网需求。

以后修改 `concept.html` 时，需同步重新生成独立包装并更新相关截图；只修改其中一份不能视为完整更新。当前文件是网页设计基线，原生 dp／sp、动效与触摸参数按计划重新验证。
