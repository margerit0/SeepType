# 紧凑候选栏交互样稿

2026-11-11 保存的界面设计参考。此提交保留当前样稿，Android 原生界面的实现仍待确认。

## 设计

- 待机工具栏与输入候选栏共用一个固定高度区域，默认按 60dp 的设计意图预览；状态切换不挤动键盘。
- 待机显示设置、浅深色、释义入口和英译开关，删除独立的“英文”行与“拾词”字样；中文空格键显示“空格”。
- 输入时不在候选栏显示拼音；每个候选英文在上、中文在下，一行通常显示 6–7 个。
- 候选数量随可用宽度与字号调整。极窄的预览会减少到 5 个，保留中文可读性；长英文单行省略，长按可查看完整释义。
- 点候选或空格提交中文，长按打开释义，点击明确的“输入英文”按钮提交英文。展开按钮显示更多候选。

预览初始展示输入中的单字候选，可用下方按钮切换待机、单字、双字与英文输入，也可点模拟键盘或在输入框内试打。宿主提供设计控件时，可以调整栏高、圆角、字号和候选密度；独立预览不依赖这些控件。

## 验证与范围

已检查英文位于中文上方、无独立拼音行、七候选与窄屏六候选、长按完整释义、中文和英文提交、展开九候选、英译开关、浅深色，以及待机和输入状态的固定高度。最窄的 286 CSS px 可用区域显示五个候选，没有横向溢出；具体视口和键盘宽度见检查记录。

词条为交互演示数据，不能作为真实词库或 Rime 输入质量的验证。网页尺寸只表达设计意图，不代表 Android 的 dp、sp、触摸目标与字体缩放已经验证。

独立预览由源片段生成，可能从获准 CDN 加载预览运行时或图标资源；键盘交互没有业务网络请求。修改源片段后，应重新生成独立预览并同步相关截图，保留源片段与预览的一致性。
