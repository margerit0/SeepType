# 紧凑候选栏交互样稿

2026-11-12 更新的界面设计参考。现有浅绿样式作为默认皮肤；“轻彩”特色皮肤改为真实字体与独立绘制的 SVG，提供三款英文字体供比较。两套共用原布局，仍处于样稿确认阶段；保存、提交或选定皮肤方向不代表确认实现 Android 界面。

追溯基线：`0322ef8`（`docs(android): preserve compact candidate bar prototype`）。后续迭代以当前文件为准。

## 皮肤

- **默认**：保留现有浅绿配色、系统字体、小写字母键标、9 CSS px 按键圆角和轻微键帽阴影。首次打开使用默认皮肤。
- **轻彩（特色）**：沿用浅灰紫底、白色圆润键帽与双层键标。字母为真实字体文本，右上显示；彩色数字和灰色符号用本轮独立绘制的圆头、断笔 SVG，左下显示。薄荷绿 Shift 带 `ab / AB`、矢量星芒和弧线，删除与确认键使用重新绘制的图标；空格键保留“空格”和细黄横线。键帽默认圆角 12 CSS px，键位、键盘高度和实际输入行为保持原设计。
- **数字／符号页**：点“123”后仍沿用字母页的 10 / 9 / 7 个字符键，同一键保留同一组字母和数字／符号。两层键标互换位置并调整大小：右上角的数字／符号小，左下角的字母大；例如 Q ↔ 1、A ↔ !、Z ↔ ~。数字页字母为 22 CSS px（窄屏 20 CSS px），数字／符号使用 16 CSS px 高的矢量框（窄屏 15 CSS px）。点“ABC”恢复字母页。
- **“123 / ABC”切换键**：白色“ABC”返回键与“123”统一使用 Fredoka 500 真实字体，保持圆润、稍厚的字形。两种状态均为 19 CSS px（窄屏 17 CSS px），字距为 0.5 CSS px（窄屏 0.4 CSS px），在原键帽中居中。与英文字母对比选项独立，键帽尺寸、位置和切换行为沿用当前设计。字体子集扩充为 `123ABC` 六个字符并内嵌；绿色大小写键继续使用原有的 Quicksand 字形。
- **大小写键**：按局部参考微调为均匀的薄荷绿底，`ab / AB` 固定使用 Quicksand 400、16 CSS px，位于左下并略微上移。上方为扁宽的四角星芒，右下为较小星芒；深绿弧线与细白弧线用独立 SVG 路径绘制，从底部绕向右上角。小写字标为浅薄荷色，切到大写时显示更亮的 `AB`；原键帽尺寸、键位和输入行为保持一致。
- **英文字体对比**：暂以 Nunito 500 为轻彩的推荐候选，也可切换 Quicksand 500 或 Patrick Hand 400。仅切换英文字母键标与下方字形样例，数字副标与键位固定，便于比较。中文候选与释义标签使用 Noto Sans SC，英文释义使用 Nunito。字体选择仍待用户确认。
- **键帽副标可操作**：字母页点按输入字母，长按约 480ms 输入对应数字或符号；数字／符号页点按输入数字或符号，长按输入对应字母。键盘操作可用 Alt+Enter 输入副标。移动指针超过 10px 会取消长按计时。候选栏的长按仍查看完整释义。
- 两套都支持浅色、深色和跟随系统。皮肤与外观独立选择；换肤保留当前文字、英译开关、外观和数字／字母页状态，独立预览刷新后可恢复选择。默认皮肤的数字页保持原设计，本轮双标交换仅应用于轻彩皮肤。
- 进入方式：下方“待机” → 左侧设置图标 → “皮肤”中的“默认 / 轻彩”。设置页在原键盘区域内提供皮肤、外观和英译三行选项。
- 下方新增的“轻彩字体”属于样稿对比控件，点字体名会直接进入轻彩皮肤；控件不属于 Android 键盘布局。可以保留当前输入比较字形，并在刷新后恢复字体选择。

先前从参考图提取的位图键标已停用并从当前运行样稿中移除。矢量源文件见 [skin-assets/soft-pop-vectors.svg](skin-assets/soft-pop-vectors.svg)，字体来源与许可见 [fonts/README.md](fonts/README.md)。原始参考图仅作设计对照，不作为按键渲染资源；默认皮肤继续使用原来的系统字体。

## 设计

- 待机工具栏与输入候选栏共用一个固定高度区域，默认按 60dp 的设计意图预览；状态切换不挤动键盘。
- 两套皮肤共用 216 CSS px 键盘区域，字母键盘为四行共 33 个按键，键位、宽度、行距与基线一致。轻彩的字母页和数字／符号页均为 33 个按键，两页键位完全对应；双层字形在原键帽内部交换位置。
- 待机显示设置、浅深色、释义入口和英译开关，删除独立的“英文”行与“拾词”字样；中文空格键显示“空格”。
- 输入时不在候选栏显示拼音；每个候选英文在上、中文在下，一行通常显示 6–7 个。
- 候选数量随可用宽度与字号调整。极窄的预览会减少到 5 个，保留中文可读性；长英文单行省略，长按可查看完整释义。
- 点候选或空格提交中文，长按打开释义，点击明确的“输入英文”按钮提交英文。展开按钮显示更多候选。
