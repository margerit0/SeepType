# 阶段 2：候选窗口原型

状态：2026-10-31，设计待用户明确确认。仅模拟交互，不安装输入法，不调用翻译服务，不读取其他应用输入。

## 打开与修改

用浏览器直接打开 `index.html`。它内嵌所需预览资源，不依赖开发服务器。页面底部“上一方案 / 下一方案”切换紧凑型与学习型；两套方案状态独立。

`ime-candidates.html` 是手工编辑的源文件，`index.html` 是生成文件。修改后执行 `./build-preview.ps1`；脚本依赖 Python 和本机 visualize 1.0.66 的 `scripts/render.py`，其他机器可用 `-Renderer` 指定位置。没有该工具仍可打开已生成的 index.html，不应手工改生成文件来替代源文件。

也可在本目录运行 `python -m http.server 8765 --bind 127.0.0.1`，访问本机 8765 端口。仅用于设计预览，不是输入法服务。没有 npm 包或待安装框架。

## 两套方案

- 紧凑型（推荐）：横排，每页 5 项，中文 18px、英文 13px，英文为辅助信息。窗口上限 640px，长英文单行省略，F2 或“查看释义”查看完整内容。
- 学习型：纵排，每页 3 项，中英均 17px，英文在上且颜色更醒目，340px 宽，固定位置展示当前候选的完整释义。更便于读英文，但遮挡更高、翻页更多。

仅比较两套，不默认要求首版同时实现两套原生布局。

## 操作

1. 选上方场景，或在拼音框用英文键盘输入内置拼音。这里只是模拟映射，非中文输入引擎。
2. 方向键切换候选，PageUp / PageDown 翻页。空格、页内数字、普通点击（包括英文行）提交中文。
3. `Ctrl+Shift+Enter` 提交当前候选英文；或右键候选 / 点“候选操作”，再点明确的“输入英文”。Shift+F10 打开菜单，Esc 关闭。
4. F2 / “查看释义”展开完整英文；没有可靠释义留空且不可输入英文。输入英文不会自动添加空格。
5. 关闭学习模式后当前轮保留行高，重试/新组合恢复单行；重新开启时下一轮恢复双行。
6. 提交当前组合或按 Esc 后打开设置，可调整字号、学习模式、英文快捷键。备用为 Alt+Enter；这些键在真实应用中的冲突尚未测试。

“重试本场景”开始新组合，不清空已提交文字。刷新会清空练习文字。外观/字号/开关/快捷键偏好可在本地预览包装或宿主中保存，练习文本不放入持久化状态。
