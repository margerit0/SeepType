- entries.json：中文精确词形、类别、显示英文、实际提交英文、来源引用、修改说明、重点标记及审核记录。
- sources/entries.json：未经改写的源词条、源文件行号与逐条 SHA256。
- source.lock.json：来源、快照、完整源文件哈希、原文件头与许可核对记录。
- NOTICE.txt 和 licenses/CC-BY-SA-4.0.txt：必要署名、修改说明和完整数据许可证。

源词条与改编词库遵循 CC BY-SA 4.0。许可范围仅为词库数据，质量审核状态不增加许可限制，也不代表软件许可证已经确定。

[审核页](../../docs/lexicon-review.html)可按类别、状态和重点条目筛选，修改英文或记录逐条决定，再下载审核 JSON。初始释义由 Codex 整理，程序验证没有冒充人工审核。审核署名为审核者填写的记录，不是数字签名或身份认证。

显示与提交目前使用同一英文文本。保留两个字段以便审核，但当前导出器会拒绝字段不一致，避免显示与实际输入产生差异。多义词只采用一个明确列出的常用义，不根据输入上下文自动猜义。

使用方法、验证结果和接续见 [词库流程](../../docs/lexicon.md)。
